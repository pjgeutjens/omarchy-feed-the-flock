## Short post

I’m sharing Feed the Flock, an Omarchy plugin for organizing notes and feeding
them into Herdr agents.

I’ve been using it heavily while building the plugin itself. It keeps incoming
thoughts out of the active agent turn, lets me order them by section, and sends
them when the agent is ready. You can still feed an urgent note immediately.

It feels ready for other people to try, so I’m putting it out there.

## Marketplace description

Feed the Flock captures voice or typed notes, arranges them in buckets and
sections, and sends them to Herdr agents in a controlled order. The compact
Omarchy panel handles capture, routing, queue state, and feed control. A local
workspace handles editing, attachments, reordering, and submitted history with
mouse and keyboard controls.

## README opening

Feed the Flock is an Omarchy plugin for people who collect prompts and feedback
faster than an agent can handle them. Capture a thought without interrupting
the current turn, place it in a section, and decide whether it should wait in
the queue or run now.

The plugin sends notes through Herdr when the selected agent is ready. Notes
stay visible and editable until delivery, and the queue remains independent
from whichever bucket you are browsing.
