# Feed the Flock publication kit

This folder is a working publication package for Feed the Flock. Open
`index.html` to review the visual direction and read `copy.md` for text that can
be adapted to a marketplace listing, README, or personal announcement.

The package is deliberately small. The intended public set is:

- one desktop-context image of the Omarchy panel;
- one full workspace image;
- one short recording of a note moving through the feed.

`preview.png`, which is the filename used by the Omarchy Plugins marketplace.

The two recordings from September 3 are useful source footage, but neither
should be published whole. One is 88 seconds and changes into a development
transcript. The other is nine minutes of real development work. A clean demo
will be shorter and easier to follow than an edit assembled from either one.

## Files

- `index.html` — local portfolio page
- `publication.css` — page styling
- `copy.md` — announcement, listing text, and captions
- `discord-posts.md` — two community-post drafts
- `marketplace-submission.md` — unsubmitted marketplace issue body
- `capture-plan.md` — final screenshot and recording instructions
- `assets/` — selected source images

No publication or upload is performed from this folder.
