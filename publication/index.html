Feed the Flock: An Omarchy plugin for Herdr

Capture thoughts.
Shape the queue.
Feed your agents.

Feed the Flock is a prompt manager and Herdr session feeder. Capture prompts, organise them in buckets and sections, and send each one when the selected agent is ready.

My ideas were arriving faster than the agent could handle them. I built Feed the Flock so I could keep working instead of waiting to submit the next prompt.

Viewer in action
InputVoice and text
DeliveryHerdr agents
ControlMouse or keyboard
StateLocal and persistent

Why it exists

Ideas arrive faster than agents finish.

Sending every thought into an active turn makes the conversation hard to steer. Feed the Flock stores the next instructions separately. You decide which section is current, what waits behind it, and what needs to run now.

  1. 01Capture

    Record or type a note into the selected section.

  2. 02Arrange

    Reorder notes and sections without rewriting the queue.

  3. 03Choose

    Set the current destination and add waiting sections.

  4. 04Feed

    Send notes one by one or in a batch when the agent is ready.

The workspace

The queue remains visible while the document changes.

The full workspace handles editing, drag and drop, attachments, submitted history, and Vim-like navigation. Browsing another bucket does not hide or replace the active delivery queue.

Current and next

Delivery state stays attached to the note.

Submitted work becomes history. The active note remains readable while the agent works, and pending notes stay ordered underneath it. Urgent work can skip the wait with Feed Now.
