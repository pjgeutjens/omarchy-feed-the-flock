# Final capture plan

Use one neutral demonstration bucket. Avoid source code, private paths, real
agent conversations, and notes about defects in the plugin.

## Demonstration content

Bucket: `Release notes`

Sections:

- `Review`
  - Check the installation instructions against a clean Omarchy system.
  - Confirm that the global feed shortcut is documented.
- `Documentation`
  - Add one screenshot of the compact panel.
  - Write a short example of section-by-section feeding.
- `After release`
  - Collect feedback from the first users.

Attach one harmless interface screenshot to the first Documentation note.

## Screenshot 1: panel in context

- Keep the panel in the upper-right area of the desktop.
- Show the Release notes bucket and Review section.
- Select an idle Herdr target with a short pane name.
- Leave one waiting section visible.
- Keep the feed stopped so the image does not imply background activity.
- Capture at the native screen scale with no terminal or notification open.

## Screenshot 2: workspace

- Open the Release notes bucket.
- Show Review and Documentation together.
- Select one pending note so the keyboard focus is visible.
- Keep one submitted note, one active note, and two pending notes in view.
- Include an attachment icon, but leave its preview closed.
- Check that the title says Feed the Flock everywhere.

## Short recording

Target length: 20–30 seconds. Record without microphone audio.

1. Open the panel and choose the Review section.
2. Add Documentation to the waiting queue.
3. Open the workspace.
4. Use `J` once to move the selection.
5. Start the feed.
6. Show the current note becoming active in Herdr.
7. End with Documentation still shown as the waiting section.

Do not include installation, configuration, debugging, or source changes. The
recording should demonstrate one complete feed transition and then stop.

## Export targets

- Keep the full-resolution PNG sources.
- Export screenshots as PNG at their captured dimensions.
- Export the recording as H.264 MP4, 1080p or the native capture size, with no
  audio track.
- Keep the final public set to two screenshots and one recording.
